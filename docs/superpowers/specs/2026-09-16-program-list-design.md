# 华丽节目单排版设计

## 目标

使用 LaTeX 制作一份 A4 竖版、单页、中文节目单，既适合屏幕预览，也适合打印。节目名称必须完整保留用户给出的原文，不改写、不纠正语气或标点。

## 视觉方案

采用“金色剧院海报 + 深蓝夜幕”的舞台风格：

- 页面底色为深蓝色，辅以细微的金色装饰线和星点；
- 顶部使用大标题、英文副标题和金色分隔装饰，形成剧院演出海报的入口；
- 五个节目使用编号徽章、金色节目序号和独立卡片分隔，形成清晰的纵向观看节奏；
- 底部增加闭幕装饰和简短的演出落款，不引入未提供的演出时间、地点或人员信息；
- 中文字体优先使用系统可用的 CJK 字体，并提供字体回退，避免中文缺字。

## 内容顺序

节目按照用户给出的顺序排版：

1. 比不是这样的！！！
2. 汪汪！
3. 汪 汪 汪
4. 汪汪往汪汪～
5. 我是一只比洛！

## 交付物

- `output/节目单.tex`：可编辑的 LaTeX 源文件；
- `output/节目单.pdf`：编译后的单页 PDF；
- `tmp/pdfs/`：仅存放渲染检查用的临时 PNG，不作为最终交付物。

## 技术与验证

- 使用 XeLaTeX 编译，以支持中文字体和 Unicode 标点；
- 依赖尽量使用常见宏包，避免复杂外部资源；
- 编译后用 Poppler 将 PDF 渲染成 PNG，检查文字是否缺失、边框是否越界、卡片是否重叠、底色和金色文字是否有足够对比度；
- 使用 PDF 文本提取确认五个节目均按原文、按顺序出现；
- 若环境缺少 XeLaTeX 或 Poppler，明确记录缺失项，不伪造视觉验证结果。

## 不做的内容

- 不添加用户未提供的节目说明、时间、地点、演员或主办方；
- 不制作多页节目册、复杂目录或动态交互效果；
- 不引入与节目单无关的项目代码或仓库重构。
