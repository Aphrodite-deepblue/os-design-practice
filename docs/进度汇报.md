各位老师、同学，大家好。我代表我们小组汇报本次操作系统课程实践的进展，主要介绍我们做什么、目前完成了什么，以及下一步的安排。

我们小组的选题是“基于 xv6 的优先级调度与饥饿避免机制”。我们计划在现有教学操作系统上扩展进程调度功能，让高优先级任务优先获得运行机会，同时通过 Aging，也就是等待越久、调度优先级逐步提高的方式，缓解低优先级任务长期得不到运行机会的问题。项目还会提供优先级查询和设置功能，并通过测试验证实际效果。

小组目前按五个模块分工，分别负责进程优先级数据、优先级调度器、Aging 机制、系统调用与用户命令，以及测试与实验。我负责第五部分，主要承担测试程序编写、对比实验和结果整理。

目前，我们已经完成开发基线的建立，以及进程优先级数据模块的实现。

首先，项目已建立 GitHub 仓库，引入 xv6 原始代码作为基线，并整理了构建运行说明。根据已有验证记录，原版系统能够正常编译、启动并运行基础命令，为后续修改和对照实验提供了基础。

其次，任务 A 已经完成进程优先级数据模块，包括优先级字段、默认值、合法范围检查，以及子进程继承父进程优先级的处理。在进程创建和回收时，也会初始化或重置相关数据，并预留了后续统计等待时间需要的字段。这部分代码已经提交到主分支。

在基础验证方面，最新版本的 Linux 和 macOS 构建都已通过，Linux 上原有用户测试和崩溃恢复测试也通过了。仓库还记录了环境问题和优先级读取时锁保护问题的处理过程。

目前的阶段性成果是，进程优先级数据已经接入内核，基础回归验证已经通过。优先级调度器、Aging 和优先级控制接口仍需要继续开发，新增功能的专项测试也需要补充。

下一步，我们会在已有数据模块的基础上，完成优先级调度策略和控制接口，让用户能够设置优先级，并观察到不同优先级对运行机会的影响；随后接入 Aging 机制，完成各模块的联调。

我负责的测试工作会与开发同步推进。首先验证默认优先级、设置和查询、子进程继承以及非法参数等情况；再检查高优先级任务是否获得优先调度、同优先级任务是否都能持续运行。

接着构造高低优先级任务竞争处理器的场景，比较开启和关闭 Aging 后，低优先级任务的等待和运行情况，验证防饥饿机制是否发挥作用。

最后，在相同实验条件下，对比原版轮转调度、仅优先级调度和加入 Aging 的优先级调度，收集任务完成时间、等待情况等数据，分析不同方案的效果和取舍。同时继续运行原有测试，检查后续修改是否影响系统基本功能。

我们会保存测试脚本、运行日志、截图和实验图表，并整理到课程设计报告和演示材料中，让结果能够复现，也能清楚体现每个人的工作。

以上是我们小组目前的进展和下一步安排，谢谢大家。
